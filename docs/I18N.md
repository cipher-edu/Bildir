# Ko‘p tillilik (i18n)

Tillar: **uz** (default), **ru**, **en**, **kaa** (qoraqalpoq).

## Frontend

- Storage: `localStorage.bildir_locale`
- Provider: `frontend/src/i18n/I18nProvider.tsx`
- Lug‘atlar: `frontend/src/i18n/locales/`
- API so‘rov: `X-Locale` + `params.lang` (`frontend/src/lib/api.ts`)

## Backend

- Yordamchi: `backend/utils/i18n_fields.py`
  - `locale_from_request`
  - `pick_i18n`
  - `ensure_i18n_bucket`
  - `localize_options`
- Kontent to‘ldirish:

```bash
python manage.py fill_content_i18n
python manage.py fill_content_i18n --force
```

## Model maydonlari

| Domen | i18n maydonlar |
|-------|----------------|
| News | title, summary, body, meta_* |
| Survey | title, description |
| Question | text, help_text, options[].text_i18n |
| Officials | position, department, biography, … |
| Risk | title, description |

Admin / API yozish: `title_ru`, `title_en` yoki `title_i18n: {…}` (`merge_i18n_payload`).
